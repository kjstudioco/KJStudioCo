# KJStudioCo Website

Premium responsive static website for KJStudioCo — Design / Creative / Marketing.

## Files
- `index.html` — semantic page structure, service descriptions, project concepts, and contact links
- `styles.css` — responsive cream / charcoal / gold design system and layouts
- `script.js` — accessible mobile navigation, scroll reveals, and current-year footer

## Preview locally
Open `index.html` in a browser. An internet connection is required for Google Fonts and the externally hosted Unsplash photography.

## Deploy
This is a static site. No build command is needed.

### Netlify
1. Open https://app.netlify.com/ and choose **Add new project → Import an existing project**.
2. Connect GitHub and choose `kjstudioco/KJStudioCo`.
3. Set branch to `main`, leave the build command empty, and set publish directory to `.`.
4. Deploy. Netlify will provide a temporary `*.netlify.app` URL.
5. Add `kjstudioco.com` in **Domain management** and follow Netlify's DNS instructions when ready.
